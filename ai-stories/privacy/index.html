Privacy Policy — AI Stories Uploader

Last updated: October 5, 2026 · Owner: Trax Palmer

AI Stories Uploader (“the App”) is a personal tool used by Trax Palmer to upload original AI-generated story Shorts to his own YouTube channel. It is not a multi-user product and is not offered as a service to the public.

What the App accesses

With the owner’s explicit Google sign-in consent, the App requests only the YouTube Data API scope https://www.googleapis.com/auth/youtube.upload. That permission is used solely to upload videos to the authenticated owner’s YouTube account.

Data storage

  • The OAuth token is stored only on the owner’s machine (local file), not on a public server.
  • The App does not run a cloud database of user accounts.
  • Video files are uploaded from the owner’s machine to YouTube via Google’s API.

Data sharing / selling

No personal data is shared with third parties for advertising or analytics beyond what Google/YouTube already process as part of normal API and YouTube service use. No data is sold.

How to revoke access

You can revoke the App’s access at any time at myaccount.google.com/permissions. After revoking, delete any local token file on the owner’s machine to fully clear local credentials.

Third-party terms

Use of YouTube via this App is also subject to the YouTube Terms of Service and the Google Privacy Policy.
